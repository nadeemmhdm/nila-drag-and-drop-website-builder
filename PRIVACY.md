# Privacy

## Local build

Nila's core local editor is designed to work without an account and without analytics or telemetry by default.

## Network access

Future network features such as GitHub export or catalog synchronization must be explicit, documented and separable from core offline editing.

## Hosted deployments

A hosted operator may add its own authentication/storage infrastructure. Such deployments must publish their own privacy notice describing what they collect and why. The upstream project must not silently enable tracking for self-hosters.
