# Contributing

Thanks for helping build Nila.

## Development

1. Fork or clone the repository.
2. Use Node.js 22+.
3. Run `npm install`.
4. Run `npm run dev`.
5. Before submitting changes run `npm run check`.

## Pull requests

Keep changes focused, document user-visible behavior, avoid unrelated dependency additions and include tests when the relevant testing layer exists.

## Components and templates

Only contribute code/assets that can legally be redistributed under their license. Preserve required attribution and license notices. Paid/proprietary component code must not be copied into the repository without explicit redistribution rights.

## Security

Do not use public issues for vulnerabilities. Follow `SECURITY.md`.
